15.  Есть генератор, сделать с его помощью массив

``` python
def generate():
    for x in range(10):
        yield x
```


> Оператор yield приостанавливает выполнение функции и возвращает значение, сохраняя состояние. При следующем вызове выполнение продолжается с того же места.
